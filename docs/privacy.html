lgpwmng プライバシーポリシー

  • 対象: Chrome 拡張機能 lgpwmng
  • 最終更新: 2026-08-27

1. 要約

lgpwmng は、利用者が端末内に登録した認証情報を、利用者の操作に応じてログインフォームへ 入力するための拡張機能です。

  • lgpwmng は、いかなる情報も外部サーバーへ送信しません。
  • 拡張は外部 API・CDN・クラウド同期・分析基盤に接続しません。ネットワーク通信を行うコードを 一切含みません。
  • 取り扱う情報はすべて、利用者の端末内（chrome.storage）に保存されます。
  • 認証情報は、マスターパスワードから導出した鍵で暗号化して保存します（PBKDF2 + AES-GCM）。
  • 開発者は、利用者のデータを取得・閲覧・販売・第三者提供しません。取得していないため、 提供も販売もできません。

2. 取り扱う情報

lgpwmng は、利用者が自ら登録・操作した範囲で次の情報を扱います。

種類内容発生元
認証情報ログインID、パスワード、第二パスワード、PIN 等利用者が設定画面で入力、または「このログイン画面を設定」時にページ上の入力済みの値を取り込み
組織識別情報自治体コード、団体コード、所属コード、職員番号 等同上
任意のフォーム入力値利用者がサービスごとに定義した任意の入力項目の値同上
対象ページの URLサービス判定に使うオリジン（プロトコル + ホスト名 + ポート）とパス利用者が拡張アイコンを操作したときの現在のタブ／フレームの URL
入力欄の構造情報入力欄の種別・id / name / CSS セレクタ・フォーム内位置・ラベル文言・フレームの識別情報「このログイン画面を設定」実行時のページ走査
サービス名利用者が付けた業務システムの名称（初期値はページタイトルまたはホスト名）利用者の入力
アカウント名・区分アカウントの名称と通常 / 管理者の区分利用者の入力
メモ利用者が任意に記載する備考利用者の入力

扱わない情報

  • 閲覧履歴（利用者が訪れたページの記録）、タブの一覧、ブックマーク
  • Cookie、セッショントークン、ページ本文
  • 利用者の氏名・メールアドレス・アカウント登録情報（lgpwmng には利用者登録がありません）
  • 利用状況・操作ログ・クラッシュレポートなどのテレメトリ

ページの走査は「このログイン画面を設定」を実行したときだけ行い、対象は入力欄 （input / select / textarea）の構造と、そのときの入力値に限られます。ページ本文・ リンク・画像などは取得しません。常駐する content script はなく、ページを継続的に監視しません。

URL の扱いについて

lgpwmng は閲覧履歴を収集しませんが、URL は扱います。具体的には次の 3 つだけです。

  1. 利用者が拡張アイコンを操作した時点の、現在のタブ／フレームの URL を読み取る
  2. 利用者が登録したログイン画面の URL 条件（オリジン + パス）を、暗号化 Vault に保存する
  3. 入力の直前に、現在の URL がその条件に一致するかを照合する（誤ったサイトへ認証情報を 入力しないための安全機構です）

利用者が拡張を操作していない間、lgpwmng は URL を読み取りません。閲覧したページを記録したり、 一覧を作ったりすることもありません。読み取った URL が端末外へ出ることもありません。

Chrome ウェブストアはこうした URL の取り扱いを「web browsing activity（ブラウザがやり取りする ドメインや URL を含む、利用者が要求・操作する Web リソースに関する情報）」として分類するため、 Developer Dashboard の申告では Web history にも該当するものとして届け出ています。 これは閲覧履歴を収集しているという意味ではなく、上記 3 つの用途で URL を扱っているという申告です。

3. 利用目的

取り扱う情報は、次の目的のためだけに利用します。

  1. ログインフォームへの入力補助 — 利用者が選択したアカウントの登録値を、登録済みの入力欄へ入力する。
  2. サービス／アカウント設定の管理 — 対象 URL、入力項目、共通値、アカウントを保存・表示・編集する。
  3. バックアップ — 利用者の操作により、暗号化されたバックアップファイルを出力・復元する。
  4. 利用者が明示的に作成する共有用ファイル — 利用者が選択したアカウントだけを、暗号化ファイルとして出力・取り込みする。

これ以外の目的（分析、機能改善のための収集、プロファイリング、広告）には利用しません。

4. 外部送信

lgpwmng は認証情報・URL・フォーム情報等を外部サーバーへ送信しません。

  • 拡張のコードには fetch / XMLHttpRequest / WebSocket / EventSource / navigator.sendBeacon を含む通信 API の呼び出しがありません。
  • 外部ドメインのスクリプト・スタイル・フォント・画像を読み込みません（CDN 不使用）。 すべてのリソースは拡張パッケージ内に含まれています。
  • 分析（Google Analytics 等）、広告、テレメトリ、クラッシュレポート、外部エラー収集 （Sentry 等）、自動更新チェック、クラウド同期のいずれも行いません。
  • Google アカウント連携・OAuth・Native Messaging を使用しません。
  • 閉域ネットワーク（LGWAN 等）の端末でも、外部接続なしに全機能が動作します。

拡張が通信を行わない設計であることは、manifest.json に host_permissions を持たないこと、 および自動テスト（npm test）で通信 API とリモートコード参照の不在を検査していることでも 担保しています。

5. 保存

保存先内容保持期間
chrome.storage.local暗号化済みの Vault（登録データ全体）、KDF パラメータ、および非機密の設定情報（データ利用への同意バージョン等）利用者が削除するまで
chrome.storage.sessionアンロック中の導出鍵ブラウザ終了時、または「ロック」実行時まで
Service Worker のメモリ復号済みの VaultService Worker が停止するまで（永続化しません）
  • 保存先はすべて利用者の端末内です。開発者や第三者のサーバーには保存しません。
  • chrome.storage.local に平文で置くのは、同意バージョン（privacyConsentVersion）のような 認証情報を含まない設定情報だけです。認証情報・URL 条件・入力欄の情報は、すべて暗号化された Vault の中にあります。
  • マスターパスワードそのものは保存しません。ハッシュも保存しません。 正否は、 AES-GCM の認証タグにより復号に成功するかどうかで判定します。したがって、マスターパスワードを 忘れた場合、開発者を含め誰も登録済みの認証情報を復元できません。
  • 鍵導出は PBKDF2-SHA256（310,000 回、16 バイトのランダムソルト）、暗号化は AES-GCM 256bit で、 いずれもブラウザの Web Crypto API を使用します。独自の暗号アルゴリズムは実装していません。
  • 復号済みの Vault を永続保存しません。 ディスクに書き出すのは暗号化された状態のものだけです。
  • セッションキー（導出鍵）は chrome.storage.session にのみ保持します。この領域はブラウザの 終了時に破棄され、アクセスレベルは TRUSTED_CONTEXTS（拡張自身のページのみ）に設定しています。 Web ページ側からは参照できません。
  • ページ側へ注入するコードには Vault 全体を渡しません。入力が必要になった項目の値だけを、 入力実行時に引数として渡します。
  • 拡張を削除すると、chrome.storage 上のデータは Chrome によって削除されます。

6. 初回の開示と同意

lgpwmng は、利用者が同意するまで、ページの URL も入力欄の情報も読み取りません。

拡張アイコンを初めて押したとき、popup に「lgpwmng のデータ利用について」という画面が表示され、 次の内容を示します。

  • 扱う情報（現在のページの URL、ログインフォームの入力欄の情報、設定時に入力済みの値。 ユーザーID・パスワード等を含む）
  • 用途（ログイン入力補助）
  • 端末内でのみ処理・保存し、外部サーバーへ送信しないこと

「同意して利用を開始」を押して初めて、現在のタブの URL の取得を含む通常の処理が始まります。 それ以前は、chrome.tabs.query() の呼び出しも、ページへのコード注入（走査・取り込み・入力）も 行いません。この制御は画面側だけでなく、要求を受ける Service Worker 側でも確認しています。

同意した内容は、同意した開示のバージョン（privacyConsentVersion）として chrome.storage.local に記録します。認証情報は含みません。扱う情報の内容を変更した場合は バージョンを上げ、改めて同意を求めます。現在の同意状態は、設定ページの 「マスターパスワード / バックアップ」タブ →「この拡張について」で確認できます。

7. 共有ファイル・バックアップファイル

利用者が明示的に操作したときだけ、暗号化ファイルを端末内へ出力します。自動生成・自動送信は 行いません。

アカウント共有（lgpwmng-share-*.json）

  • 出力されるのは、利用者がチェックして選択したアカウントだけです。未選択のアカウントは ファイルに含まれません。
  • ファイル全体を AES-GCM で暗号化します。平文の JSON として出力されることはありません。
  • 共有用パスフレーズはマスターパスワードとは独立に指定します（8 文字以上）。 このパスフレーズは chrome.storage / localStorage / sessionStorage / Vault のいずれにも 保存されず、処理中だけ使用します。
  • 作成されたファイルは、利用者が指定した保存先に置かれるだけです。自動送信・自動アップロード・ 共有フォルダ監視は行いません。 受け渡しは利用者自身が行います。

マスターバックアップ（lgpwmng-backup-*.json）

  • Vault 全体を、利用者が指定したバックアップ用パスフレーズ（マスターパスワードとは独立、 8 文字以上）で暗号化して出力します。こちらも自動送信は行いません。

出力したファイルの管理（保管場所、受け渡し経路、廃棄）は利用者の責任範囲です。パスフレーズは ファイルとは別の経路で伝達することを推奨します。

8. データ販売・第三者提供・広告

  • データ販売はありません。 利用者のデータを第三者へ販売・貸与しません。
  • 広告目的の利用はありません。 広告の配信、パーソナライズ広告・リターゲティング広告への データ利用を行いません。
  • 第三者提供はありません。 データが端末外へ出る経路が存在しないため、提供が発生しません。
  • 人による閲覧はありません。 開発者を含む誰も、利用者のデータを読むことができません。

9. Chrome ウェブストア「限定的な使用（Limited Use）」への適合

lgpwmng は、Chrome ウェブストアのユーザーデータポリシー（Limited Use の要件を含む）に準拠します。

  • 許可された使用: 取り扱う情報は、本拡張の単一の目的である「利用者が端末内に登録した認証情報を ログインフォームへ入力する補助」と、それを支える設定管理・バックアップ・共有機能の提供のためだけに 使用します。
  • 許可された転送: データを他者へ転送しません。転送を行う経路自体がありません。 利用者自身が作成した暗号化ファイルの受け渡しは、利用者の操作によるものです。
  • 広告の禁止: パーソナライズ広告・リターゲティング広告・興味関心に基づく広告のために データを使用または転送しません。
  • 人による閲覧の禁止: 開発者およびその関係者が利用者のデータを読むことはありません。

10. 権限と、その必要性

lgpwmng が要求する権限は次の 3 つだけです。<all_urls> などの広範な恒久的ホスト権限は 要求しません。

権限用途
activeTab利用者が拡張アイコンから操作した現在のタブに限り、そのページへアクセスするため
scripting現在のページの入力欄を検出し、利用者が選択した登録値を入力するため
storage暗号化された Vault・設定・セッション状態を端末内に保存するため

ページへのアクセスは、利用者が拡張アイコンを押した時点に限られます。バックグラウンドで ページを走査したり、閲覧中のサイトを記録したりすることはありません。

Chrome ウェブストアの Developer Dashboard では、扱うデータの種類として Personally identifiable information / Authentication information / Website content / Web history を申告しています。いずれも端末内で扱うだけで、外部へ送信することはありません （分類の理由は「2. 取り扱う情報」および docs/webstore/privacy-practices.md を参照してください）。

詳細は docs/webstore/permissions.md を参照してください。

11. 子どものプライバシー

lgpwmng は業務システムのログイン補助を目的とした業務用ツールであり、子どもを対象としていません。 年齢に関する情報を含め、利用者に関する情報を収集しません。
