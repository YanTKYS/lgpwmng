# アイコン点検結果

Chrome ウェブストアの Store icon には、拡張パッケージ内の `icons/icon128.png` がそのまま
使われます。別途アップロードする必要はありません。

## 現在のアイコン

| ファイル | サイズ | 形式 | 用途 |
| --- | --- | --- | --- |
| `icons/icon16.png` | 16x16 | PNG (RGBA) | ツールバー・favicon 相当 |
| `icons/icon32.png` | 32x32 | PNG (RGBA) | Windows の高 DPI 環境 |
| `icons/icon48.png` | 48x48 | PNG (RGBA) | `chrome://extensions` の一覧 |
| `icons/icon128.png` | 128x128 | PNG (RGBA) | Chrome ウェブストアの Store icon、インストール時のダイアログ |

意匠は、角丸の青（`#1b64c4`）の正方形に白の南京錠を配したものです。

## 点検結果

| 点検項目 | 結果 |
| --- | --- |
| 128px アイコンが存在し、`manifest.json` の `icons` / `action.default_icon` から参照されている | OK |
| PNG 形式・実寸どおり（128x128 ちょうど） | OK |
| 潰れていない（16px でも南京錠の形が判別できる） | OK |
| 余白過多でない | OK（余白なし。下記の補足を参照） |
| 背景との区別が付く | OK。アイコン自身が不透明な青の背景を持つため、明るい背景でも暗い背景でも輪郭が出る。角のみ透過 |
| 他サービスの商標・ロゴ・ブランド色を含まない | OK。一般的な南京錠の図形のみで、既存サービスを想起させる要素はない |
| 縁取り・大きなドロップシャドウがない | OK |
| 遠近をつけていない（正面向き） | OK |

**機能上の問題はないため、v0.6.0 では既存アイコンをそのまま使用します。**

## 補足: 推奨される透明余白との差異

Chrome ウェブストアの画像ガイドラインは、正方形のアイコンについて
「実際の意匠は 96x96 とし、四辺に 16px ずつの透明な余白を足して 128x128 にする」ことを
推奨しています（他の形状のアイコンと視覚的な重さを揃えるためのガイドです）。

現在の `icon128.png` は角丸正方形が 128x128 いっぱいに広がっており、この 16px の余白が
ありません。

- これは掲載時の見え方に関する**推奨事項**であり、審査で拒否される要件ではありません。
- 余白が不足している方向のため、「余白過多で小さく見える」問題は起きていません。
- 一覧上、他の拡張よりわずかに大きく見える可能性があります。
- 意匠を変えずに調整できます（96x96 へ縮小して中央に配置し直すだけ）。掲載後の見え方を
  確認したうえで、必要なら別リリースで差し替えてください。その場合も `manifest.json` の
  記述は変更不要です。

## 変更する場合の注意

- 4 サイズすべてを同じ意匠で更新してください（`manifest.json` の `icons` と
  `action.default_icon` の両方が 4 サイズを参照しています）。
- サイズは実寸ちょうどにしてください（Chrome は拡大縮小しますが、`chrome://extensions` で
  警告が出ることがあります）。
- アイコンを差し替えたら `npm test` を実行し、公開用 ZIP に 4 サイズが含まれることを
  確認してください。
