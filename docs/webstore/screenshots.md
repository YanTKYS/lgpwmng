# スクリーンショット撮影計画

Chrome ウェブストア Developer Dashboard → **Store listing** → Graphic assets 用の画像を用意する
ための手順です。

## 仕様（現行の Chrome ウェブストア）

| 種別 | サイズ | 形式 | 要否 |
| --- | --- | --- | --- |
| Store icon | 128x128 px | PNG | **必須**（パッケージ内の `icons/icon128.png` が使われる） |
| Screenshot | **1280x800 px**（または 640x400 px） | PNG / JPEG | **必須**（最低 1 枚、最大 5 枚） |
| Small promo tile | 440x280 px | PNG / JPEG | **必須** |
| Marquee promo tile | 1400x560 px | PNG / JPEG | 任意 |
| YouTube 動画 | — | URL | 任意（公式ドキュメントは Graphic assets の列挙に含めている） |

Small promo tile（440x280）は**必須**です。公式ドキュメントは
「You must provide one small, 440x280-pixel promotional image」「Small: 440x280 pixels (required)」と
明記しており、これが無いアイテムは、ストア上で small promo tile があるアイテムより後ろに表示されます。
任意なのは Marquee promo tile（1400x560）だけです。

- スクリーンショットは 1280x800 を推奨します（高解像度ディスプレイで見栄えがよく、表示時は
  640x400 へ縮小されます）。
- 文字が多い画面を撮る場合、縮小後に読めるかを確認してください。読みにくい場合は
  640x400 で撮り直します。
- 縦横比が合わない画像はアップロードできません。撮影後にキャンバスサイズを 1280x800 へ
  合わせてください（画面をそのまま拡大せず、余白を足して合わせます）。

## 撮影前の準備

1. **Reviewer Demo だけを使う。** 実在の業務システムは開かない。
   - <https://yantkys.github.io/lgpwmng/reviewer-demo.html>
   - <https://yantkys.github.io/lgpwmng/reviewer-demo-frame.html>
2. **ダミー値だけを登録する。**
   - 自治体コード `123456` / ユーザーID `test-user` / パスワード `test-pass-123`
   - サービス名は「サンプル申請システム」など架空の名称にする
   - アカウント名は「標準ユーザー」「システム管理」など一般的な名称にする
3. **画面に写り込ませないもの。**
   - 実在する認証情報
   - 実在する業務システム名・組織名
   - 実在する自治体内部の URL・ホスト名（アドレスバーに `yantkys.github.io` 以外の
     業務系ホスト名を写さない）
   - ブックマークバー、他のタブのタイトル、拡張機能の一覧、通知、ユーザー名
4. Chrome を新規プロファイル（またはゲストプロファイル）で起動し、ブックマークバーを非表示にする。
5. パスワード項目は既定のマスク表示のままにする（「表示」を押した状態では撮らない）。

## 撮影する画面（4 枚）

### 1. popup でサービス／アカウントを選択する画面

- 準備: Reviewer Demo を開き、サービスとアカウントを 2 件（標準ユーザー / システム管理）登録済みにする。
- 撮影: Reviewer Demo のページ上で拡張アイコンをクリックし、popup が開いた状態。
  サービス名、アカウント一覧、「ログイン情報を入力」ボタンが写るようにする。
- ねらい: 「アカウントを選んで入力する」という主機能が一目で伝わること。
- ファイル名: `assets/screenshot-1-popup.png`

### 2. ログイン画面設定画面（setup）

- 準備: Reviewer Demo を開き、popup →「このログイン画面を設定」を実行する。
- 撮影: 入力項目の候補一覧（自治体コード / ユーザーID / パスワードの 3 行）と、
  表示名・区分・種別・対象入力欄の設定が写る状態。
- ねらい: 任意の入力項目を登録できること、対象入力欄を利用者が確認できることが伝わること。
- ファイル名: `assets/screenshot-2-setup.png`

### 3. options のサービス／アカウント管理

- 準備: サービスを 2 件程度登録しておく（いずれも架空の名称）。
- 撮影: popup →「サービス一覧」→「サービス」タブ。サービス一覧とアカウント一覧、
  管理者バッジが写る状態。
- ねらい: 複数サービス・複数アカウントを管理でき、管理者アカウントが区別されることが伝わること。
- ファイル名: `assets/screenshot-3-options.png`

### 4. アカウント共有画面

- 撮影: options →「マスターパスワード / バックアップ」タブ →「アカウント共有」→
  「共有用ファイルを作成」を開き、サービスごとのアカウント選択と共有用パスフレーズ欄が写る状態。
- 注意: パスフレーズ欄は空のまま撮る（入力済みの状態にしない）。
- ねらい: 選択したアカウントだけを暗号化ファイルとして受け渡せることが伝わること。
- ファイル名: `assets/screenshot-4-share.png`

## 撮影方法

1. Chrome のウィンドウサイズを 1280x800 に合わせる（DevTools のデバイスツールバー、または
   `chrome.windows` を使わずに OS 側でウィンドウサイズを指定する）。
2. popup を撮る場合、popup は独立したウィンドウとして表示されるため、画面全体を撮ってから
   1280x800 へトリミング／余白調整を行う。
   - popup を開いた状態でスクリーンショットを撮るには、popup 上で右クリック →「検証」で
     DevTools を開くと popup が閉じにくくなります。
3. 画像編集ソフトで、背景色（白または淡いグレー）の 1280x800 キャンバスの中央に配置する。
   画面を引き伸ばさない。
4. PNG で保存し、`docs/webstore/assets/` へ置く。

## 保存先

```text
docs/webstore/assets/
  screenshot-1-popup.png     （必須。最低 1 枚）
  screenshot-2-setup.png
  screenshot-3-options.png
  screenshot-4-share.png
  small-promo-440x280.png    （必須）
  marquee-1400x560.png       （任意）
```

画像は撮影者が追加してください。リポジトリには、撮影前の時点では
[assets/README.md](assets/README.md) だけが置かれています。

## Small promo tile（440x280、必須）の作り方

スクリーンショットとは目的が異なります。画面をそのまま貼るのではなく、拡張が何をするものかを
一目で伝える画像にします。

- **スクリーンショットの流用は避けます。** 縮小すると読めなくなります。
- **文字は最小限にします。** 半分のサイズに縮めても成立するかを確認してください
  （プロモ画像はロケール別に差し替えられないため、文字が多いと多言語で不利になります）。
- 案: 濃紺（`#1a4f8a` 前後）の背景に、`icons/icon128.png` と同じ南京錠の意匠を大きく配置し、
  右側に「lgpwmng」と短い一言（例:「業務システムのログイン入力補助」）を添える。
- 余白を十分に取り、縁取り・強い影は付けません（UI 側で枠が付くことがあります）。
- 実在の組織名・システム名・認証情報は入れません。
- Google のブランド要素（Chrome ロゴ等）は使いません。

Marquee promo tile（1400x560）は任意です。より目立つ掲載枠を狙う場合にのみ用意します。

## 撮影後の確認

- [ ] 実在の認証情報・組織名・業務システム名・内部 URL が写っていない
- [ ] パスワード欄がマスク表示されている
- [ ] ブックマークバー・他のタブ・通知・ユーザー名が写っていない
- [ ] 1280x800 px ちょうど（または 640x400 px ちょうど）である
- [ ] 640x400 へ縮小しても文字が読める
- [ ] 4 枚が同じ縮尺・同じ背景で統一されている
- [ ] Small promo tile（440x280、**必須**）を用意した
- [ ] Small promo tile が半分のサイズに縮めても読める
