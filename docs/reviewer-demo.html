lgpwmng Reviewer Demo — サンプルログイン画面

Chrome 拡張機能 lgpwmng の動作確認用に用意した、架空の業務システムを模した ログイン画面です。実在するシステム・組織・ドメイン・認証情報とは一切関係ありません。

このページはデモです。 「ログイン」を押しても認証は行われず、どこへも送信されません。入力された値はこのページの JavaScript が画面へ表示するだけで、ページ外へ出ることはありません。

確認手順（概要）

  1. このページを開いた状態で、lgpwmng のアイコンをクリックします。
  2. 初回はマスターパスワード（8 文字以上、任意の値）を設定します。
  3. 「このログイン画面を設定」を選び、上の 3 項目を登録します。
  4. ダミー値を保存し、このページを再読み込みします。
  5. 再度アイコンをクリックし、アカウントを選んで「ログイン情報を入力」を実行します。
  6. 3 つの入力欄へ値が入ること、ログインボタンが自動で押されないことを確認します。

詳細な手順は docs/webstore-review.md を参照してください。frame / iframe 内のログインフォームに対応していることを確認する場合は、 frame 版のデモを使用してください。
