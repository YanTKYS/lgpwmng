lgpwmng ドキュメント

業務システムのログインフォームへ、利用者が端末内に登録した認証情報を入力するための Chrome 拡張機能です。外部サーバーへの送信は行いません。

プライバシー

  • プライバシーポリシー

    取り扱う情報、利用目的、保存場所、暗号化、外部送信を行わないことの説明。Chrome ウェブストアの Privacy Policy URL に指定するページです。

審査用デモ

  • Reviewer Demo（標準版）

    架空の業務システムを模したサンプルログイン画面。自治体コード / ユーザーID / パスワードの 3 項目。frame / iframe を使わない基本ケースです。

  • Reviewer Demo（iframe 版）

    ログインフォームを iframe に埋め込んだ追加ケース。frame / iframe 対応の確認用です。
