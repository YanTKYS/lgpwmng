    この拡張について

    lgpwmng / 外部通信なし・端末内のみで動作します。認証情報は AES-GCM で暗号化して保存されます。

    扱う情報とその用途

    ログイン入力補助のため、次の情報を扱います。いずれも端末内でのみ処理・保存し、外部サーバーへ送信しません。

    扱う情報用途保存先
    現在のページの URL 対象のログイン画面を判定し、入力の直前に照合する 登録した URL 条件（オリジン + パス）を暗号化 Vault へ
    ログインフォームの入力欄の情報 入力先の入力欄を特定する 暗号化 Vault へ
    入力済みの値・登録した値
    （ユーザーID・パスワード等）    		 ログインフォームへ入力する 暗号化 Vault へ

    情報を扱うのは、利用者が拡張アイコンから操作したときだけです。ページを常時監視する 常駐スクリプトはなく、閲覧履歴・利用状況・テレメトリは収集しません。データの販売・ 第三者提供・広告目的の利用も行いません。
